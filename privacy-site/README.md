# StimPad — Privacy Policy Site

Publish via GitHub Pages from this folder on **OrehRuoy/StimPad**.

URL: https://orehruoy.github.io/StimPad/privacy-policy.html

## Enable Pages
1. Push `privacy-policy.html` and `index.html` to StimPad repo root (or `/docs` if using docs source)
2. Repo Settings → Pages → Deploy from branch `main` / root
3. Add URL to App Store Connect, Play Console, and in-app Settings
