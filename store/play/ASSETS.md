# Play graphics

Capture these on a phone and a tablet running a Play-installed build. Export them yourself. This folder does not generate images.

| Asset | Size | Notes |
| --- | --- | --- |
| App icon | 512×512 PNG | Use the shipped icon. No rounded-corner mask; Play applies one. |
| Feature graphic | 1024×500 PNG | App name and a few sound tiles. No tiny text. |
| Phone screenshots | 1080×1920, 4 to 8 | Home grid, player with Head Floss, sleep timer, paywall. |
| 7-inch tablet | Play's 7-inch size | Home grid showing more columns. |
| 10-inch tablet | Play's 10-inch size | Same four moments as the phone set. |
| Adaptive icon preview | 432×432 source | Foreground, background, and monochrome already live in `assets/branding/android/`. Check the preview in Play Console after upload. |

How to capture:

1. Install the internal-track build. Set the device language to English.
2. On a phone, set the display so a screenshot is 1080×1920 (or crop a taller capture to that).
3. Shoot the home grid with the banner visible and not covering the bottom row.
4. Open a sound, turn Head Floss on, and shoot the player.
5. Open the sleep timer at 15 minutes and shoot that sheet.
6. Open the paywall and shoot the price and Watch Ad row.
7. Repeat the home grid on a 7-inch tablet and a 10-inch tablet.
8. Do not show another app's audio, a debug menu, or a test-card dialog.
