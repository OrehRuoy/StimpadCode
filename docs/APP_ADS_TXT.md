# app-ads.txt

After the Play listing has a developer website, serve this file at the root of that domain (`https://<developer-website>/app-ads.txt`):

```
google.com, pub-5356882403986713, DIRECT, f08c47fec0942fa0
```

AdMob starts app-ads.txt verification once the Android app is linked to the Play store (App settings → Add store). Until that link exists, the Android app stays unlinked and fill can be limited.
